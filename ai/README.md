
# cumulocity-ai-agent template

## Summary
This microservice demonstrates how to integrate **Large Language Models (LLMs)** with **Cumulocity IoT** using **Spring AI**.  
It provides example REST endpoints for guardrails, prompt engineering, stateful AI conversations, and tool-enabled AI actions such as retrieving time or creating alarms.

### REST Endpoints
All endpoints are organized into dedicated controllers under the base path:

```
/api/ai-agent
```

#### **SimpleChatController**
Basic examples of interacting with the LLM.

- `GET /api/ai-agent/chat`  
  Free-form chat with an LLM.

- `GET /api/ai-agent/chat/device/unstructured`  
  Returns a natural-language status report for a device.

- `GET /api/ai-agent/chat/device/structured`  
  Returns a structured `DeviceSummary` generated by the LLM.

- `GET /api/ai-agent/chat/device/full-response`  
  Returns the raw `ChatResponse` including metadata.

---

#### **GuardrailController**
Applies a strict system message so the model answers **only Cumulocity-related questions**.

- `GET /api/ai-agent/guardrails/chat`  
  Returns an answer constrained to Cumulocity topics.  
  Out-of-scope questions trigger a fixed response.

---

#### **PromptController**
Shows prompt templating and context stuffing.

- `GET /api/ai-agent/prompt/templated`  
  Generates a 5-line SmartREST template using placeholder values.

- `GET /api/ai-agent/prompt/context-stuffing`  
  Demonstrates passing device data into the prompt.

---

#### **StatefulController**
Adds conversation memory using Spring AI `ChatMemory`.

- `GET /api/ai-agent/state-ful/chat`  
  The model remembers previous interactions (e.g., tenant name).

---

#### **ToolController**
Demonstrates LLM-triggered tool execution (time retrieval, alarm creation).

- `GET /api/ai-agent/tools/get-time-context`  
  LLM may call a tool to return the server date/time.

- `GET /api/ai-agent/tools/take-action-alarm`  
  Creates a Cumulocity alarm based on user text.

- `GET /api/ai-agent/tools/multi-tool-test`  
  The LLM selects between multiple tools and may call several.

---

## How to run locally

1. **Build project**
   ```bash
   mvn clean install
   ```

2. **Create a Microservice application in Cumulocity**
   ```json
   {
     "key": "cumulocity-ai-agent",
     "name": "cumulocity-ai-agent",
     "contextPath": "cumulocity-ai-agent",
     "type": "MICROSERVICE",
     "manifest": {},
     "requiredRoles": [
       "ROLE_INVENTORY_READ",
       "ROLE_INVENTORY_CREATE",
       "ROLE_INVENTORY_ADMIN",
       "ROLE_MEASUREMENT_READ",
       "ROLE_ALARM_ADMIN"
     ],
     "roles": []
   }
   ```

3. **Subscribe the microservice** in the UI.

4. **Get bootstrap credentials**
   ```
   GET /application/applications/{applicationId}/bootstrapUser
   ```

5. **Add credentials** to `src/main/resources/application-dev.properties`.

6. **Run locally using dev profile**
   ```bash
   java -Dspring.profiles.active=dev -jar ai-0.0.1-SNAPSHOT.jar
   ```

## Purpose
This template provides a simple starting point for building **AI-powered Cumulocity microservices**, demonstrating guardrails, dynamic prompting, tool integration, and conversational state management.
